Web Development Topics

1. HTML5

Used for structuring web pages with semantic tags like header, main, and footer.

2. CSS3

Handles styling, colors, spacing, and responsive layouts with Flexbox and Grid.

3. JavaScript

Adds interactivity, DOM manipulation, and API calls on the client side.

4. Node.js

JavaScript runtime environment used to build fast backend servers.

5. Express.js

Minimal Node.js framework for routing, middleware, and REST APIs.

6. MongoDB

NoSQL document database that stores data in flexible JSON-like documents.

7. React

Component-based frontend library for building single-page applications.

8. SQL

Standard language for querying and managing relational database tables.

9. Git & GitHub

Version control tools for tracking code changes and collaborating.

10. REST API

Architecture style using HTTP methods like GET, POST, PUT, and DELETE.
